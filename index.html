計算のルール

メインカラーを見た目の明るさに忠実な色空間 OKLCH（明度 L・彩度 C・色相 h）に変換し、色相を基準に他の3色を決めています。

明るい色色相はそのまま、明度 L = 0.96、彩度はメインの 1/4（上限 0.04）。ほんのり色づいた白になります。
暗い色色相はそのまま、彩度はメインの 0.8 倍（上限 0.14）。明度 0.40 から、白字とのコントラストが基準を満たすまで暗くします。
強調色色相を 180° 回した補色。メインが暗めなら明度 0.72、明るめなら 0.50 にして明暗の差もつけます。メインがグレーに近いときはオレンジ系に固定します。

コントラスト比は WCAG の定義（相対輝度の比）で計算しています。7 : 1 以上は AAA、4.5 : 1 以上は AA の基準です。

計算はすべてこのブラウザの中で行われます。ソースコードと Python 版は GitHub にあります。
