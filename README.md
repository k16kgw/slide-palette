# スライド配色メーカー

メインカラーを1つ決めると、PowerPoint などのスライド用に次の3色を計算するツールです。

- **強調色** … メインカラーに合うアクセント
- **明るい色** … 黒字を載せる背景
- **暗い色** … 白字を載せる背景

ブラウザで動く Web 版と、コマンドラインで動く Python 版があり、どちらも同じ計算結果になります。

## Web 版

GitHub Pages で公開しています：**https://OWNER.github.io/REPO/**

- 色はカラーコード・RGB・HSL・HSV・色相の角度・OKLCH・CMYK のどれでも入力できます。カラーピッカーや色相環から選ぶこともできます。
- 生成した配色を当てはめたスライドの見本が表示され、ページ全体もその配色になります。
- 各色の HEX / RGB をワンクリックでコピーできます。URL に色の指定が入るので、そのまま共有できます。
- 計算はすべてブラウザ内で行われ、入力した内容はどこにも送信されません。

## Python 版

外部ライブラリは不要です（Python 3.8 以降）。

```
python color_palette.py "#0066CC"
python color_palette.py 210 "hsl(0,70%,45%)"     # 複数まとめて比較
python color_palette.py "#0066CC" --target 4.5  # コントラスト基準を緩める
```

```python
from color_palette import palette
p = palette("hsl(210,100%,40%)")
p["accent"], p["light"], p["dark"]   # (217, 150, 19) (234, 243, 255) (5, 70, 140)
```

## 入力できる形式

| 形式 | 例 |
|---|---|
| カラーコード | `#0066CC`、`0066CC`、`#06C`（数字だけの3桁は `#` 必須） |
| RGB | `rgb(0,102,204)`、`rgb(0%,40%,80%)` |
| HSL | `hsl(210,100%,40%)` |
| HSV / HSB | `hsv(210,100%,80%)` |
| 色相の角度だけ | `210`、`hue(210)`（彩度70%・明度45%の HSL とみなす） |
| 色相＋彩度・明度 | `hue(210, 80%, 45%)` |
| OKLCH | `oklch(0.55 0.15 250)` |
| CMYK | `cmyk(100%,50%,0%,20%)` |

## 計算のルール

メインカラーを、見た目の明るさに忠実な色空間 OKLCH（明度 L・彩度 C・色相 h）に変換し、色相を基準に他の3色を決めます。

| 色 | ルール |
|---|---|
| 明るい色 | 色相はそのまま、L = 0.96、C = メインの 1/4（上限 0.04） |
| 暗い色 | 色相はそのまま、C = メインの 0.8 倍（上限 0.14）。L = 0.40 から、白字とのコントラスト比が基準（既定 7:1）を満たすまで下げる |
| 強調色 | 色相 +180°（補色）。メインが暗め（L < 0.6）なら L = 0.72、明るめなら 0.50。C はメイン以上（最低 0.15）。メインがグレーに近い（C < 0.03）ときは h = 50°（オレンジ系）に固定 |

sRGB で表せない色になる場合は、色相と明度を保ったまま彩度を下げて収めます。コントラスト比は WCAG 2 の定義（相対輝度の比）で計算しています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | Web 版のページ |
| `palette.js` | Web 版の計算部分（`color_palette.py` の移植） |
| `color_palette.py` | Python 版（コマンドライン・ライブラリ） |
| `tests/check_consistency.py` | Python 版と Web 版の結果が一致するかの確認（Node.js が必要） |

計算ルールを変えるときは `color_palette.py` と `palette.js` の両方を直し、次のテストで一致を確認してください。

```
python tests/check_consistency.py
```

## GitHub Pages の設定

リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存すると、数分後に上記の URL で公開されます。
